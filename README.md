# Guia do Sistema Solar

Site de uma página feito com **HTML e CSS puros** para a atividade da Aula 06 de Web Design (Facens) – *CSS: Seletores, Cores, Tipografia e Layouts Básicos*.

A página apresenta o Sol e os oito planetas desenhados só com CSS, cartões com um resumo de cada planeta, uma tabela comparativa, uma linha do tempo de missões espaciais, curiosidades e um formulário de contato ilustrativo. Todo o estilo fica no arquivo externo `style.css`, ligado ao `index.html` pela tag `<link>`.

## Propriedades vistas em aula

- `color`, `background-color`, `font-family` e `font-size`
- `margin` e `padding` (formato uniforme e com vários valores)
- `border`, `width` e `height`
- `display`: `block`, `inline` e `flex`
- `position`: `relative`, `absolute` e `fixed`, com `top`, `right`, `bottom` e `left`
- `text-align`: `center` e `justify`
- Seletores de classe (`.cartao`, `.botao`, `.secao`) e de ID (`#cabecalho`, `#rodape`, `#voltar-topo`)

## Propriedades adicionais

- **Design:** `border-radius`, `box-shadow`, `text-shadow`, `line-height`, `letter-spacing`, `max-width`, `text-transform`, degradês com `background-image`
- **Interatividade:** `:hover`, `:focus`, `transition`, `transform`, `cursor`, `opacity`, `scroll-behavior`
- **Responsividade:** `@media` para tablet (até 900px) e celular (até 600px), `flex-wrap`, `gap`, `overflow-x`

## Como abrir

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` em qualquer navegador.

Não é preciso instalar nada.
