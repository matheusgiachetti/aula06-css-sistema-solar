# Guia do Sistema Solar

Atividade da Aula 06 de Web Design (Facens) sobre CSS: seletores, cores, tipografia e layouts básicos.

É um site de uma página só, feito com HTML e CSS puros, sem JavaScript. Tem os oito planetas desenhados com CSS, um cartão para cada planeta, uma tabela comparando os números, uma linha do tempo com missões espaciais, algumas curiosidades e um formulário de contato de exemplo. Todo o CSS fica no `style.css`, ligado ao `index.html` pela tag `<link>`.

## Propriedades da aula

- `color`, `background-color`, `font-family` e `font-size`
- `margin` e `padding`, com um valor só e com vários valores
- `border`, `width` e `height`
- `display`: `block`, `inline` e `flex`
- `position`: `relative` (cartões), `absolute` (etiquetas) e `fixed` (botão de voltar ao topo), junto com `top`, `right`, `bottom` e `left`
- `text-align`: `center` e `justify`
- Seletores de classe (`.cartao`, `.botao`, `.secao`) e de id (`#cabecalho`, `#rodape`, `#voltar-topo`)

## Propriedades adicionais

- Visual: `border-radius`, `box-shadow`, `line-height`, `letter-spacing`, `max-width`
- Interação: `:hover`, `:focus`, `transition`, `transform`, `cursor`, `opacity`, `scroll-behavior`
- Responsividade: `@media` para tablet (até 900px) e celular (até 600px), `flex-wrap`, `gap`, `overflow-x`

## Como abrir

Baixe ou clone o repositório e abra o `index.html` no navegador. Não precisa instalar nada.
